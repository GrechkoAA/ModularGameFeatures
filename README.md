# Modular Game Features (Модульные игровые фичи)
Набор многократно используемых, готовых к внедрению в производство функций Unity, разработанных как независимые модули.
Каждая функция изолирована, расширяема и легко интегрируется в другие проекты.
Все модули покрыты юнит-тестами и легко проверяемы, что обеспечивает надежность и предсказуемость их работы.

> ⚡ **Каждый модуль сопровождается примером использования**, который демонстрирует основные возможности и способы интеграции в проект.

**Каждый модуль:**

- Является автономным
- Имеет минимальное количество зависимостей
- Следует принципам чистой архитектуры
- Разработан с учетом масштабируемости и расширения
- Может быть интегрирован в другой проект с минимальной настройкой

### 💰 Currency Bank

Модуль управления игровыми валютами с изолированной бизнес-логикой и операциями над балансом.

**Возможности:**

- Хранение нескольких типов валют  
- Безопасные операции добавления, списания и установки баланса  
- Проверка достаточности средств  
- Расширяемая архитектура (поддержка новых типов валют)  
- ✅ Полное покрытие юнит-тестами  

**⚙️ Code Generation**

Генератор автоматически создает `enum CurrencyType` на основе добавленных валют.

`Tools → CodeGenerator → Currency`

### 📝 Logger
Логгер спроектирован так, чтобы **не влиять на производительность в Release-сборках**.

Все вызовы логирования **могут быть полностью удалены на этапе компиляции** через `Conditional`, что означает:

- в **Development Build** → логирование активно  
- в **Release Build** → вызовы логгера полностью исключаются компилятором  

Это позволяет:

- не тратить производительность на логирование в рантайме  
- не оставлять debug-код в продакшене  
- использовать одинаковый код для dev и release сборок  

---

### ✨ Возможности

- Логирование: `Info`, `Warning`, `Error`, `Exception`  
- Поддержка нескольких sinks одновременно  
- Исключение логов из Release-сборок через `Conditional`  

---

### 📦 Доступные sinks

- `UnityConsoleSink` — вывод в Unity Console  
- `FileLoggerSink` — запись логов в файл  

---

### 🛡️ Обработка исключений (важно)

Логгер позволяет централизованно логировать и пробрасывать исключения одновременно:

```csharp
if (_rigidBody == null)
{
    throw _logger.Exception(new NullReferenceException(nameof(_rigidBody)));
}
```
